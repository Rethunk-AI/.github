# Rethunk-AI organization templates

Organization-level GitHub configuration for [Rethunk-AI](https://github.com/Rethunk-AI).
Houses the public org profile and default community health files used when a
repository does not define its own.

## Contents

| Path | Purpose |
|------|---------|
| [`profile/README.md`](profile/README.md) | Public organization profile on github.com/Rethunk-AI |
| [`SECURITY.md`](SECURITY.md) | Default vulnerability reporting policy |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask for help |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contribution expectations |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Community standards |

Repo-specific docs (for example `bakeoff`'s `SECURITY.md` / `CONTRIBUTING.md`)
override these defaults when present.
